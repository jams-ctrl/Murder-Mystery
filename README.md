# Murder Mystery
#### Video Demo:  (https://youtu.be/mzB1xSaPEO0)
#### Description:

When I began this project, I wanted to make an application that used a combination of Flask, HTML, and Javascript. I originally found it very interesting how these 3 languages can be used in tandem, and wanted to push them to their limits through this project. I chose a murder mystery setting because I wanted to make an interactive web application where users would be taken on an adventure of suspense, mystery, and fun.

My idea was to use HTML and CSS to do the styling, javascript to do all the client-side code, and flask to verify the answers and return dynamic HTML when necessary. I started with the main page, and instantly my knowledge of CSS was tested. I could make everything look good on my main monitor using margin-left and margin-right and such, but the second I went to my macbook, everything looked jumbled. Because of this, I decided to use flexbox, a feature of CSS that would scale the webpage to a screen's dimensions. Because of my lack of knowledge on flexbox, I relied on chatGPT to generate CSS for me that integrated flexbox into layouts and ideas I already had. Soon, the styling of the main page was done, and all that was left was to add the images. For each image I added, I found it really tedious to download the image, remove the background, then add it to my code. After a little digging, it seemed there was no fix for this, and so i continued on.

Once all the pictures were added, I then started integrating Javascript into my HTML to have unique reactions when each of the images are clicked on. I originally wanted to use flask for this, but I realized that the reloading of the page for every click was going to get tiring, and fast. So then I used Javascripts event handler to make each image react upon click, sometimes revealing a new image, other times showing a riddle. I made a noteboard and an evidence board on the left and right sides of the 'game square' to log all of the users actions. Everytime the user clicked on an image, Javascript would display a blurb on the noteboard giving the user some data about what they just clicked on. If the click was important and unveiled evidence, I then made sure to add a bullet point to my evidence board. This board was a bulleted list, unlike the paragraph my noteboard had, and for every new evidence the user discovered I would add it to the evidence board for the user to keep track of their findings.

Then came the hard part. The final part of my escape room was a riddle that needed to be answered to move on, and I had to make sure that the user had found all pieces of evidence in the room before they could attempt the riddle. I accomplished this by using Javascript booleans which also worked to make sure that the same evidence wasn't added onto the evidence board twice. Upon answering the riddle, I had Flask verify whether the answer was correct or not, and redirect the user to another page if so. However, if the inputted answer was wrong, I had a problem. I had to redirect the user to the same page where all the Javascript had now reset and the user would have to do the entire room again just to attempt the riddle once more. To solve this issue, I created a duplicate of the room where all actions were frozen except the riddle's prompt and the answer box, giving the user infinite tries with no repercussions.

With the answer to the riddle now being right (rubber duck!) the user is now redirected via Flask to a page where they must guess the suspect. I once again used chatGPT to generate the CSS for this page which included a Gemini-generated mugshot of all 5 possible suspects, an evidence board, and a Who Committed The Crime answer box. The intention of this page was for the user to use method of elimination to guess who committed the crime, because of all the articles found at the crime scene, only one criminal is found to not be wearing all of them. In this case, if the user's guess was wrong, I had no problem of redirecting them to the exact same page once again.

As for the files in my project, index.html is the game page, retry.html is the static retrying page for if the player gets the riddle wrong, guess.html is the page where the user guesses the criminal, and win.html is where the user wins. In my static folder, I have all the images used and the CSS for the entire project. In app.py, I have some Flask where values are verified and templates are returned.

Once the user's answer has been verified once again via Flask, they are whisked away to a victory page promising my ever-greater comeback.
